# 엑셀 A열 → 애니 포스터

파일 탐색기에서 **실행.cmd** 또는 **start.cmd**를 더블클릭하세요. VS Code의 PowerShell 터미널에서는 다음 명령으로 실행합니다.

```powershell
.\실행.cmd
```

실행 오류가 나면 콘솔 창을 유지하며 내용을 startup.log에 기록합니다.

## 엑셀 작업

1. 처음 실행하면 첨부한 애니로그-전체-2026-10-12.xlsx를 자동으로 불러옵니다. 다른 파일은 위쪽 **엑셀 A열 불러오기**로 선택합니다.
2. 첫 시트 **A열의 제목**을 순서대로 읽습니다. ‘작품명’, ‘제목’ 같은 머리글과 빈칸은 제외합니다. 첨부 파일은 **451개 제목**입니다.
3. 한국어 제목으로 TV와 영화를 함께 검색합니다. TMDB에서 애니메이션 장르로 등록된 작품만 보여주며, 위쪽 후보 목록에서 작품을 바꿀 수 있습니다. 같은 이름의 실사 영화는 제외합니다.
4. 해당 작품의 **일본어 등록 포스터를 최대 9장** 보여줍니다. **숫자 키 1~9**를 누르거나 이미지를 클릭하면 원본 한 장이 저장되고 다음 미저장 제목으로 이동합니다.
5. **← 되돌아가기**는 이전 제목으로 돌아갑니다. **다음 / 건너뛰기 →**는 현재 제목을 저장하지 않고 넘깁니다. 왼쪽 목록에서 제목을 직접 선택할 수도 있습니다.

검색 결과가 없으면 왼쪽 검색어를 수정하고 검색하세요. 검색어를 바꾸거나 작품 후보를 바꿔도 저장명은 **엑셀 A열 원래 제목**을 유지합니다. 원본 엑셀은 수정하지 않습니다.

TMDB에 작품이 없거나 일본어로 등록된 포스터가 없으면 안내합니다. 9장 미만이면 등록된 만큼 보여줍니다. 다른 언어 포스터는 섞지 않습니다. 첨부 파일 첫 제목 ‘20세기 전기목록’은 확인 당시 한국어 제목으로 검색되지 않았으므로 직접 검색어를 보완하거나 건너뛸 수 있습니다.

## 첫 포스터 전체 자동 저장

위쪽의 **미저장 전체 · 첫 포스터 저장** 버튼을 누르면 엑셀 전체를 처음부터 확인해, 저장되지 않은 제목마다 **첫 번째 일본어 포스터 원본 한 장**을 자동으로 저장합니다. 작품 후보는 자동 검색에서 처음 나오는 애니메이션을 사용하며, 포스터 순서는 수동 화면의 1번과 같습니다.

- 현재 선택한 제목 앞에 있는 미저장 항목도 처리합니다.
- 이 버튼은 **이미 저장된 제목을 항상 제외**합니다. 수동 모드의 중복 방지 체크를 꺼 두어도 자동 저장에서는 추가 사본을 만들지 않습니다.
- A열의 원래 한글 제목으로 저장하며 밑줄은 공백으로 바꿉니다. 원본 엑셀은 수정하지 않습니다.
- 진행률과 저장·기존 제외·검색/포스터 없음·실패 건수를 화면에 표시합니다.
- 작품 검색 결과나 일본어 포스터가 없으면 결과를 기록하고 다음 제목으로 넘어갑니다.
- **자동 저장 중지**를 누르면 현재 서버 요청이 끝난 뒤 멈춥니다. 저장한 파일은 유지되며, 다시 시작하면 그 파일들을 건너뜁니다.
- 저장 폴더의 **bulk_results_날짜_시간.csv**에서 각 엑셀 행의 결과를 확인할 수 있습니다. 실패하거나 검색되지 않은 제목은 왼쪽 목록에서 골라 수동으로 다시 확인하세요.

자동 저장 중에는 수동 선택과 제목 이동을 잠시 막습니다. 인증 오류, 요청 제한 또는 연속된 오류로 계속 진행할 수 없으면 중지 사유를 표시합니다.

## 저장명과 중복 방지

- A열이 약사의_혼잣말이면 **약사의 혼잣말.jpg**로 저장합니다. 밑줄을 공백으로 바꾸고 연속 공백을 정리합니다.
- 원본 형식이 PNG/WebP이면 그 형식의 확장자를 사용합니다. 이미지 원본을 재압축하지 않습니다.
- 기본 저장 폴더는 이 프로젝트의 **downloads**입니다. 왼쪽의 **폴더 변경**에서 바꿉니다.
- **이미 저장한 제목 건너뛰기**는 기본으로 켜져 있습니다. 저장 폴더에 동일한 제목의 JPG/JPEG/PNG/WebP가 있으면 목록에서 ✓로 표시하고, 다음 제목으로 이동할 때 건너뜁니다.
- 이전 제목으로 돌아가 번호를 다시 눌러도 중복 다운로드를 차단합니다. 과거 버전에서 만든 ‘제목 (2).jpg’ 같은 파일도 인식합니다.
- 설정과 최근 위치는 유지되므로 재실행해도 저장된 제목을 다시 내려받지 않습니다. 다른 저장 폴더를 고르면 그 폴더의 파일을 기준으로 판단합니다. 저장 파일을 삭제하면 다시 미저장 상태가 됩니다.
- 체크를 직접 해제하면 같은 제목도 ‘(2)’, ‘(3)’처럼 추가 저장할 수 있습니다.
- 저장 폴더의 download_history.jsonl에는 원래 제목, 작품 ID, 선택한 포스터, 엑셀 파일·시트·행, 저장 파일명을 기록합니다.

## 키보드

| 키 | 동작 |
|---|---|
| 1~9 / 숫자 키패드 | 해당 포스터 저장, 엑셀 모드에서는 다음 미저장 제목으로 이동 |
| 방향키 왼쪽 ← / Backspace | 되돌아가기: 이전 제목 |
| 방향키 오른쪽 → | 건너뛰기: 현재 항목을 저장하지 않고 다음 미저장 제목으로 이동 |
| 검색창에서 Enter | 현재 검색어로 검색 |

키패드는 **Num Lock을 켜고** 사용하세요. 입력란을 편집할 때 숫자를 입력해도 저장되지 않습니다. 키를 계속 누르고 있어도 다음 작품까지 연달아 저장되지 않도록 처리합니다.

검색어를 편집하는 동안 방향키는 글자 커서를 이동합니다. 읽기 전용인 엑셀 저장명이나 저장 폴더에 초점이 있어도 방향키로 제목을 이동할 수 있습니다.

위쪽 **개별 검색**으로 엑셀 없이 한 작품씩 검색할 수도 있습니다.

## 설치와 검증

Python 3.10 이상과 Tkinter가 필요합니다. 실행 파일은 설치된 Python을 자동으로 찾고 Pillow가 없으면 설치합니다. 엑셀 A열 읽기는 추가 패키지 없이 동작합니다.

```powershell
.\start.cmd --check
python -X utf8 -m unittest discover -s tests -v
python -X utf8 tools/verify_live.py
```

실제 키패드 다운로드까지 확인하려면 tools/verify_live.py에 --download를 추가합니다. 저장 폴더에 같은 제목이 있으면 중복 차단을 확인하며 추가로 저장하지 않습니다. --excel "파일경로" --row 3 옵션으로 특정 엑셀 행도 확인할 수 있습니다.

API 키는 .env에 저장되며 화면의 **API 키 설정**에서 변경합니다. 키는 소스 코드와 다운로드 기록에 포함하지 않습니다. TMDB_API_KEY 환경변수가 있으면 프로그램 시작 시 우선 사용합니다.
